 
🎯OBJETIVO:
Este projeto consiste em um controle direcional para controlar o uArm Swift Pro via bluetooth, eliminando fios através de comandos intuitivos e ágeis.

A solução resolve a necessidade de uma navegação sem fio estável, integrando o software ao hardware de forma eficiente para garantir total mobilidade.



🚀 RECURSOS PRINCIPAIS:

Controle Direcional Manual: Movimente o braço robótico livremente em tempo real através de um pad direcional intuitivo.

Modo Automático: Execute sequências de movimentos ou rotinas pré-programadas de forma autônoma.

Controle de Precisão (Sliders): Ajuste fino de coordenadas, velocidade ou ângulos das juntas utilizando sliders dedicados na interface.

Conexão Bluetooth: Pareamento rápido e comunicação sem fio estável diretamente com o hardware do uArm Swift Pro.

Calibração Integrada: Ferramenta para calibrar o ponto zero e garantir a exatidão dos movimentos do braço antes da operação.

Configurações do App: Ajuste de preferências da interf
ace, sensibilidade dos controles e parâmetros de conexão.



🛠️ TECNOLOGIAS UTILIZADAS:

Figma: Wireframe wi-fi para realizar a contrução e navegação das telas, focando no design para depois focar na programação.

Android Studio: Programação, navegação e design das telas do aplicativo.

Git Hub: Permite que os outros componentes do grupo possam mexer no app pelo Android Studio, onde os integrantes do projeto dividem-se para realizarem partes do projeto, assim depois o responsável por juntar as partes atualiza o projeto.
